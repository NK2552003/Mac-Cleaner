# Mac Deep Cleaner v3.5.0 (Unreleased)

Version 3.5.0 supersedes main and PyPI version 3.2.0. Each feature has its own workspace; Care Center and its extra tools have been removed.

## Where features live

| Feature | Location |
| --- | --- |
| Storage analysis and reviewed cleanup | Storage Cleanup |
| Trash journal and restore | Storage Cleanup → Cleanup history |
| App caches and reviewed uninstall | Applications |
| Large-file review | Large files |
| Exact duplicate review | Duplicates |
| System diagnostics and maintenance | Optimize your Mac |
| Physical drives and usable volumes | Disks & volumes |
| Packages, dependencies, and services | Homebrew |
| Orphaned app leftovers | Ghost Files, opt-in from Settings |
| Dismissed Ghost locations | Settings → Ghost allowlist |
| Offline language import/export | Settings → Language |
| Scheduled safe cleanup, notifications, GitHub updates | Settings → Automation / Notifications / Updates |

The shared SVG mascot uses feature-specific accents, continuous orbit motion, and occasional eye blinks. Redraws retain animation timing; Reduce Motion stops the decorative animation.

Care Center's scheduling, cleanup profiles, custom rules, media similarity, app slimming, extra startup/browser inventory, treemap, disk trends, and HTML reports are no longer provided. Existing settings and Trash history are preserved. The native menu runs one-click safe cleanup and provides direct access to Cleanup history. Closing the window keeps only its menu bar presence. See [the pending automation features](automation.md).

## Restore and disk space

Trash moves do not free disk space until Trash is emptied. Each move is journaled before an atomic rename into a uniquely named container in `~/.Trash`. Restore refuses occupied destinations and changed identities. Finder's original-location Put Back metadata is not created.

```sh
mdc history
mdc restore ENTRY_ID
```

The private journal remains in `~/Library/Application Support/Mac Deep Cleaner/history.sqlite3`. The UI shows the newest 1,000 entries. Permanent deletion, Trash-emptying, and maintenance commands have no undo. A filesystem lock prevents overlapping cleanup and restore across app and CLI processes.

## Languages and privacy

Settings includes 42 bundled offline language packs. Missing translations fall back to English. Import and export remain in Settings; cloud generation and API-key controls have been removed. New feature translations are authored with AI during development and shipped with the app.

User filenames, paths, command output, and native operating-system interfaces are not translated. Typed safety phrases such as `UNLOCK` remain unchanged. User packs are stored in `~/Library/Application Support/Mac Deep Cleaner/locales`.

## Build and verify

```sh
.venv/bin/python -m pytest -q
NODE_PATH=/tmp/mdc-ui-check/node_modules .venv/bin/python tests/run_browser_checks.py
MDC_TEST_BROWSER=webkit NODE_PATH=/tmp/mdc-ui-check/node_modules .venv/bin/python tests/run_browser_checks.py progress
bash scripts/build.sh pkg
bash scripts/build.sh build
```

Browser tests use disposable fixtures; disk commands and external translation are simulated. No host files are cleaned during testing. See [the quality audit](quality-audit.md) for current results and boundaries.
