Open **Care center** in the sidebar. The existing storage scanner, applications, Homebrew, disks, Optimize, and Ghost Files workspaces remain available.

## Weekly policy

The agent is `~/Library/LaunchAgents/com.macdeepcleaner.weekly.plist`. It moves **regular files directly inside** `~/Library/Caches` and `~/Library/Logs` only when modification, access, and metadata-change times are all at least seven days old. It skips directories, symlinks, hard-linked files, and exclusions. Runs are bounded to 500 files and 2 GB. This deliberately narrow policy can find nothing on some Macs. It never empties Trash, processes custom rules, invokes package-manager cleanup, or removes applications. A local notification follows a run; macOS notification permissions may affect delivery.

```sh
mdc care scheduled-run --preview
mdc care schedule enable --weekday 0 --hour 10 --yes
mdc care schedule status
mdc care schedule disable
```

Keep the app/virtual environment at its installed path. After moving or reinstalling it, disable and re-enable the schedule. `launchd` may run a missed calendar event after wake. The app does not install a schedule merely by launching or updating.

## Restore and disk space

Trash moves do **not** free disk space until Trash is emptied. Each move is journaled before an atomic rename into a uniquely named container in `~/.Trash`. Use this app's history to put it back; Finder's original-location “Put Back” metadata is not created. Restore never overwrites existing files. If the original parent disappeared, create that parent yourself before retrying. Changed identities, symbolic-link substitutions, and cross-volume moves are rejected. A directory's identity does not constitute a checksum of all descendants.

```sh
mdc care history
mdc care restore ENTRY_ID
```

History is private to the current account in `~/Library/Application Support/Mac Deep Cleaner/history.sqlite3`. The UI shows the newest 1,000 entries. Permanent deletion, Trash-emptying, and maintenance commands have no undo. A filesystem lock prevents overlapping file cleanup/restore across app and CLI processes.

## Similar media and slimming

Source/CLI installs can enable image decoding with `python3 -m pip install 'mac-deep-cleaner[media]'`. Native builds bundle Pillow. Video analysis needs both `ffmpeg` and `ffprobe` on PATH. No dependency is installed automatically.

The media scan examines at most 500 media files already discovered by the main scan, with a three-minute budget checked between files. A decoder subprocess may extend that budget by its per-command timeout. Small files below the main scan's threshold and excluded folders are not included. Rotation, crop, overlays, flat images, and dark scenes can cause missed or false matches. Candidate scores measure hash similarity, not the probability that deletion is safe.

Slimming always keeps Base and English resources, plus requested language identifiers. It retains the host CPU slice when available. A copied app may lose notarization, entitlements, updater compatibility, or functionality after ad-hoc signing. Test the copy. The original is retained and no space is reclaimed until you decide what to keep. Failed jobs may leave a partial copy in Downloads.

## JSON rules

Rules target children of one literal app directory under `~/Library/Caches`. Parent traversal, recursive globs, broad cache-root globs, and executable commands are rejected. Rules never join automatic cleanup or profiles.

```json
{
  "rules": [
    {
      "name": "Editor previews",
      "path": "~/Library/Caches/com.example.editor/previews/*",
      "reason": "Generated previews; rebuilt by the editor."
    }
  ]
}
```

Validate with `mdc care rules my-rules.json`; install with `--install`, then rescan. Rules live in `~/Library/Application Support/Mac Deep Cleaner/rules.json`.

## Language coverage and privacy

The picker offers the 194 language/variant codes in the checked Google NMT registry. This is broad coverage, **not a claim that every language in the world is translated**. Forty-two bundled starter packs translate common controls; Hindi and Spanish include more Care center text. Untranslated messages fall back to English, and Settings shows the exact catalog coverage. Language packs can cover the extracted static interface across workspaces and dialogs. User filenames, paths, command output, dynamically composed messages, and some native OS UI remain unchanged. Typed safety phrases such as `UNLOCK` remain English.

For broader coverage, select a language and open **Generate a language pack**. Supply a Google Cloud Translation Basic API key, or set `MDC_TRANSLATE_API_KEY` before starting the app. The confirmation shows the source character count. Google Cloud billing/quota applies. Only bundled UI strings go to the fixed HTTPS provider endpoint; redirects and proxy settings are disabled. Credentials are neither written into packs nor returned in errors. Completed translation batches are saved locally and generation resumes after a failure. Generated translations need human review, especially safety wording.

No network request is made just by selecting a language. Offline JSON packs support other BCP-47 languages too:

```json
{"locale": "fr", "messages": {"Settings": "Paramètres", "Restore": "Restaurer"}}
```

Export the English template from Settings to obtain all source messages. Packs accept plain text only and reject unknown messages, executable markup, and directional overrides. User packs live in `~/Library/Application Support/Mac Deep Cleaner/locales`. Region packs fall back to their base language. The language preference is saved in the app's local settings and survives native-app restarts.

Provider references: [language coverage](https://docs.cloud.google.com/translate/docs/languages), [Basic REST translation](https://docs.cloud.google.com/translate/docs/reference/rest/v2/translate).

## Verification and release checks

Automated tests isolate filesystem changes in temporary homes and mock external translation/maintenance. Browser fixtures cover restoration, profile selection, review cancellation, rules, report download, localization, RTL, and responsive layouts. Swift compilation verifies the native widget. Actual scheduled launchd execution/notifications, real third-party slimmed app compatibility, and a paid translation API request remain manual acceptance checks; they are not activated during development tests.

```sh
python3 -m pytest -q
python3 -m build
swift build
# Optional browser checks (requires Playwright and Chromium):
python3 tests/care_fixture.py
NODE_PATH=/path/to/node_modules node tests/verify_care.cjs
```

Maintain the UI catalog with `NODE_PATH=/path/to/node_modules node scripts/extract_messages.cjs` (requires Acorn). Keep new user-derived content out of the source catalog and translation requests.
